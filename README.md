# Flash CS4 Recreation

A browser recreation of the Flash CS4 Professional authoring environment, written as a single HTML file.

**[Open it in your browser](https://chixinred.github.io/flash-cs4-recreation/)**

It includes drawing tools, symbols, a timeline with keyframes and classic/shape tweens, IK bones, filters, text, and saving and opening documents (including XFL export).

This is a fan project. It is not affiliated with or endorsed by Adobe. Flash is a trademark of Adobe Inc.
